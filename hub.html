Customer portal, admin panel and optional waiter app, all live on one screen

How to test

  1. On Guest 1, enter a name (e.g. Ahmad) and join. You are the table host.
  2. On Guest 2, you'll see who is hosting. Enter another name (e.g. Sara) and join.
  3. Guest 1 gets a "Sara joined the table" alert. Add dishes on either phone: the other phone shows who added what.
  4. Only the host can send the first order. Send it and watch it arrive in the Admin Live screen and the Waiter app.
  5. In Admin, go to Staff and switch the Waiter app off. The waiter is logged out, and new orders and calls go to Admin Live.
  6. Tap the bell on a guest phone to request water or the bill, then mark it done in Admin or the waiter app.
